# OcbLawnMowing V2.3 modernization plan

## Goal
Modernize the Lawn Tractor / Lawn Mowing mod for the latest 7 Days to Die line, starting from the official upstream V2.1-compatible baseline and then validating against the current V2.3 game files.

## Current baseline

- Local modernization branch: `modernize/v2.3-latest`
- Local repo before this pass was based on mod `2.3.2` / 7D2D `V1.0 exp`.
- Official upstream `OCB7D2D/OcbLawnMowing` latest release is `2.5.0`, described as 7D2D `V2.1 stable` compatibility.
- This branch has merged the upstream `2.5.0` baseline first, so V2.3 work can be handled as a smaller compatibility delta.

## Build gate

The project is still an old-style .NET Framework 4.8 C# library targeting 7D2D managed assemblies.

Verified local build command:

```bash
dotnet build LawnMowing.sln --no-restore -p:PATH_7D2D_MANAGED=/home/lancer1977/.steam/debian-installation/steamapps/common/7\ Days\ To\ Die/7DaysToDie_Data/Managed -v:minimal
```

Current local status:

- The project now builds cleanly on Linux with the current 7D2D Managed folder and the net48 reference assemblies package.
- The built `LawnMowing.dll` is copied to the repo root by an MSBuild target.
- Remaining validation is runtime smoke against the live game/mod load path.

Expected CI / future build command shape:

```bash
msbuild LawnMowing.sln \
  /p:PATH_7D2D_MANAGED=/path/to/latest/7DaysToDie_Data/Managed
```

or the repo CI path through `OCB7D2D/OcbModCompiler` once that compiler action supports the target game version.

## Modernization slices

### 1. Toolchain / game-DLL slice

- Install or provide a Windows/MSBuild/.NET Framework 4.8 build surface.
- Provide the latest 7D2D V2.3 `7DaysToDie_Data/Managed` path.
- Compile `LawnMowing.sln` against that managed folder.
- Capture compiler errors as the source-of-truth API drift list.

### 2. Harmony API drift slice

Verify every patch target still exists and matches the V2.3 signatures:

- `XUiM_PlayerInventory.GetItemCountWithMods`
- `ItemValue.GetPropertyOverride`
- `Vehicle.SetItemValueMods`
- `Vehicle.SetItemValue`
- `Block.CopyDroppedFrom`
- `EntityVehicle.ApplyDamage`
- `Audio.Manager.Play`
- `VehiclePart.SetColors`

Known upstream V2.1 delta already merged here:

- `Audio.Manager.Play` patch moved from the old `Vector3, string, int` signature to the newer `Entity, string, float, bool` signature.

### 3. Runtime mower logic slice

Compile/runtime audit the high-risk game internals used by `Library/VPMower.cs`:

- `VehiclePart.HandleEvent(...)` overloads
- `Vehicle.Event.Stopped` / `Vehicle.Event.Started`
- private `EntityVehicle.wheelBrakes` reflection
- `vehicle.entity.world`
- `World.SetBlocksRPC`
- `BlockChangeInfo`
- `BlockValue.Air`
- `Block.DowngradeBlock`
- `Block.itemsToDrop` / `Block.SItemDropProb`
- `Bag.GetSlots`, `Bag.SetSlots`, `Bag.DecItem`
- `LocalPlayerUI.GetUIForPlayer`
- `XUiC_CollectedItemList.AddItemStack`
- `ParticleEffect`
- `SpawnParticleEffectServer`

### 4. XML/XPath compatibility slice

Validate every config patch against the actual V2.3 XML files, especially:

- `items.a22.xml`
- `item_modifiers.a22.xml`
- `loot.a22.xml`
- `progression.a22.xml`
- `recipes.a22.xml`
- `traders.a22.xml`
- `blocks.a22.xml`
- `blocks.a22.grass.xml`

High-risk targets:

- trader groups: `groupVehicles`, `schematicsVehiclesMods`, `groupMeleeMods`
- progression perks: `perkLivingOffTheLand`, `perkAdvancedEngineering`, `perkTheHuntsman`
- vehicle crafting unlocks
- crop block names / growth stages / downgrade paths
- harvest/drop tags and tool categories

### 5. Asset and sound slice

Upstream V2.1 changed the sound XML to use newer `@:` prefab / wav paths and refreshed Unity bundle artifacts. For V2.3:

- Verify `Resources/LawnMowers.unity3d` loads.
- Verify vehicle prefab references still resolve.
- Verify horn, engine, blade loop, plant, and stone sounds play.
- Verify tint/emission shader behavior.
- Verify physics/collider behavior for driving and harvesting.

### 6. In-game smoke slice

Run with EAC off, client and server side installed:

- Mod loads with no red console errors.
- Recipes, schematics, items, modifiers, and icons appear.
- Lawn tractor crafts/spawns/drives.
- `F` toggle still starts/stops mowing.
- Grass/bush mowing removes blocks.
- Grass/plant/crop collectors add items to vehicle inventory.
- Crop protector avoids player crops.
- Crop reseeder consumes seed and replants.
- Stone/gore mowing damage behavior works.
- Multiplayer/dedicated server sync works.

## Done definition

A V2.3-ready modernization is done when:

- The code compiles against V2.3 `Assembly-CSharp.dll` and Unity managed DLLs.
- XML patching produces no missing-XPath errors on V2.3 configs.
- A packaged mod loads in-game with EAC off.
- The in-game smoke slice passes for driving, mowing, harvesting, reseeding, sounds, and dedicated/client sync.
- README / `ModInfo.xml` / changelog identify the verified 7D2D version.
